# Large Slotwise test package

`slotwise_20_warehouses/` is a **wholly synthetic** canonical CSV package generated by `scripts/generate_large_slotwise_sample.py`. It contains 20 warehouses, 10,000 pick locations (500 per warehouse), 5,000 SKUs (250 per warehouse), inventory and current assignments for every SKU, one order line per SKU, 10,000 package-capacity certificates, and connected picker routes.

Each SKU has two certified bins. In the revised sample, some current placements are deliberately farther from the depot than their empty alternatives. For `WH-01`, the engine produces 83 moves and 167 keeps. This mix exercises both decisions; it is not an accuracy benchmark.

To upload in Slotwise, select **all CSV files and `manifest.json`** in the folder. Enter warehouse `WH-01` (or another ID through `WH-20`). Set the snapshot field to **2026-10-31 00:00:00 UTC** (05:30:00 on 2026-10-31 in India). The package is intended for load and functional testing; the site-test certificates, measurements, inventory and demand are generated values and must never be used to manage real stock.

The canonical importer reports zero errors and zero physical incidents. Its external-evidence warning is expected because no real site has approved this synthetic data. The generator is deterministic and can recreate the package.
